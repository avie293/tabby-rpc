# Changelog

## Unreleased

### Added
- Added the Discord connection, which shows "Playing Minecraft" with the elapsed play time as Rich Presence (Fabric only for now)
- Added an image and the current menu while no world is loaded: main menu, options, multiplayer, singleplayer and world creation
- Added "Singleplayer", the name of the world and the default world icon while playing in a singleplayer world
- Added the mod loader and the Minecraft version to the second line in menus and in singleplayer
- Added "Multiplayer" and the number of players while playing on a server
- Added an option to show the address and the icon of servers, for all servers or for single ones when adding or editing them
- Added the number of players to worlds that are open to LAN
- Added "Ask to Join" for LAN worlds while e4mc is installed, requests can be answered in Discord or in the chat
- Added an option to turn join requests off
- Added an option to hide the name of singleplayer worlds
- Added a button that leads others to Tabby RPC, which can be turned off
- Added the `config/custom_rpc` folder, in which modpacks can change texts, images and buttons and use their own Discord application
- Added `/tabbyrpc reload` to reload the `custom_rpc` folder
- Added the head of the player as a small round image
